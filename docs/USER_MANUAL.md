# 제주얼마꽈 사용자 매뉴얼 (USER_MANUAL)

## 1. 개요
**제주얼마꽈**는 제주도민이 자연어로 검색하면 AI가 오프라인 매장과 온라인몰을 찾아 가격순으로 보여주고, 지도(우측)와 목록 사이드바(좌측)로 거리·가격·혼잡도를 비교하며 길찾기까지 제공하는 원스톱 가격 비교 서비스입니다.

---

## 2. 설치 및 실행 방법

### 요구 환경
- Python 3.11 이상
- Node.js 18 이상, npm

### 2.1 환경변수 설정
```bash
cp .env.example .env
```

### 2.2 패키지 설치
```bash
# 백엔드 패키지 설치
pip install -r backend/requirements.txt

# 프론트엔드 패키지 설치
cd frontend
npm install
cd ..
```

### 2.3 실행 모드

#### 개발 모드 (동시 실행)
```bash
bash scripts/dev.sh
```
- 프론트엔드: `http://localhost:5173`
- 백엔드 API: `http://localhost:8000`

#### 단독 프로덕션 서빙 (프로세스 1개)
```bash
bash scripts/build_and_serve.sh
```
- 프론트 빌드 후 `http://localhost:8000`에서 단독 제공됩니다.

## 3. 화면별 사용 방법

### 3.1 메인 홈 (`/`)
- 서비스 소개 및 제주 풍경 배너 영역을 제공합니다.
- 상단 메뉴를 통해 **가격 검색** 또는 **로그인/회원가입** 페이지로 이동할 수 있습니다.

### 3.2 가격 검색 (`/search`)
1. **자연어 검색 (F-03)**:
   - 검색창에 "우유 1L 제일 싼 곳", "라면" 등 원하는 상품을 입력하고 Enter를 누르거나 검색 버튼을 클릭합니다.
2. **내 위치 설정 (5.3.2)**:
   - 검색창 우측 `📍 내 위치` 칩을 눌러 GPS 위치를 가져오거나 특정 읍/면/동 주소를 검색하여 기준 위치를 변경할 수 있습니다.
3. **분류 및 필터링 (F-05)**:
   - 상단 정렬 버튼: `추천순`, `거리순`, `가격순`
   - 유형 필터: `전체`, `오프라인`, `온라인`
4. **오프라인 매장 비교 및 길찾기 (F-06, F-07)**:
   - 매장 카드를 클릭하면 우측 지도가 해당 매장으로 이동(flyTo)합니다.
   - 카드에 표시된 `길찾기` 버튼을 눌러 출발지 주소를 입력하면 도로 거리와 소요시간이 계산되고 지도에 경로선이 표시됩니다.
5. **온라인몰 이동 (F-08)**:
   - 온라인몰 카드를 클릭하면 안전한 검색 결과 URL로 새 탭이 열립니다.
6. **혼잡도 확인 (F-09)**:
   - 오프라인 매장명 옆의 색상 원(초록/노랑/주황/빨강)과 인원수를 통해 실시간 혼잡도를 파악할 수 있습니다.

---

## 4. 제약 사항 및 안내
- 기본 설정 상태에서는 `MockAgent`를 통해 테스트 가격 및 혼잡도를 산출합니다.
- 실제 오프라인 매장의 실시간 가격 및 위치는 모델 연동 후 업데이트됩니다.
- 로그인/회원가입 기능은 뼈대 UI 형태로 제공되며, 제출 시점에는 안내 문구가 표시됩니다.
